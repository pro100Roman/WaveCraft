# Bundled fonts

`NotoSans-Regular.ttf` is Noto Sans Regular 2.008 from the
[Noto fonts repository](https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf).
Its SHA-256 digest is
`b85c38ecea8a7cfb39c24e395a4007474fa5a4fc864f6ee33309eb4948d232d5`.

It supplies Latin subscripts and superscripts such as ₙ and ⁿ that the default
fonts and Noto Sans Symbols2 lack. It is a fallback in both proportional and
monospace families, before Noto Sans Symbols2, and is distributed under the
SIL Open Font License 1.1; see `NotoSans-OFL.txt` in this directory.

`NotoSansSymbols2-Regular.ttf` is Noto Sans Symbols2 Regular 2.003 from the
[Noto fonts repository](https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSansSymbols2/NotoSansSymbols2-Regular.ttf).
Its SHA-256 digest is
`630846d528dbe4c4981370a4d0a9475a1fd1491a129bb411f8e157cdb5de13c6`.

The font is used as the last fallback in WaveCraft's proportional and
monospace font families. It is distributed under the SIL Open Font License
1.1; see `NotoSansSymbols2-OFL.txt` in this directory.
